# Excelra Novel Target Identification Demo

Interactive demonstration of Excelra's Novel Target Identification service using WGCNA & Bayesian Networks.

## Features

- **Overview**: Service introduction and methodology workflow
- **Run Analysis**: Simulated target identification pipeline
- **Network Explorer**: Interactive gene network visualisation
- **Results Dashboard**: Target prioritisation and clinical validation

## Demo Case Study

Atopic Dermatitis / Pruritus (Dermatology)
- 25,000 genes analysed
- 12 co-expression modules identified
- 4 hub genes validated against approved drugs
- 3 novel targets identified

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
